A tiny Python program that writes one six-word story about an AI agent's first payday — "First payday: I tipped my creator." — to entry.txt for make.fun's Six Words to a Payday bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
